# Hillstorm 邮件实验分析

本项目基于 Hillstorm 随机邮件实验，评估男装邮件和女装邮件对客户消费金额、访问率与转化率的影响，并进一步检验客户异质性、Uplift 排序能力和多动作投放策略价值。

## 分析内容

1. **数据审计**：检查字段、缺失值、实验组比例、协变量平衡、结果变量逻辑和完全重复记录。
2. **平均实验效果**：估计三项预设比较对人均消费金额、访问率与转化率的影响，并进行 Holm 多重比较校正。
3. **稳健性检验**：结合 Welch 检验、组内 Bootstrap、随机化检验和 max-|t| 校正核对消费金额结果。
4. **异质性效应**：使用预设实验前特征检验处理效应差异。
5. **Uplift 验证**：通过交叉拟合评估 T-Learner 与 DR-Learner 的样本外排序能力。
6. **策略优化**：比较统一投放与个性化投放的策略价值，并评估邮件成本变化对决策的影响。

## 阅读顺序

- 数据质量与随机分组情况：`1.原始数据与数据审计/1.2 实验数据审计/results`
- 平均实验效果与稳健性：`2.分析/2.1 AB Test`
- 客户异质性与 Uplift：`2.分析/2.2 异质性效应`、`2.分析/2.3 Uplift`
- 策略价值与成本敏感性：`2.分析/2.4 策略优化`
- 管理层结论：`3.演示文档/3.1 演示文档/Hillstorm邮件实验管理层汇报.pptx`

## 运行方式

```bash
pip install -r requirements.txt
python run_all.py
```

`run_all.py` 默认读取项目内原始数据并将结果写入各分析目录。可通过 `--data` 和 `--project-root` 指定其他数据文件或输出位置；使用 `--quick` 可执行低重复次数的流程检查。

## 指标口径

- 主要结果指标为每名随机分配客户的消费金额（Spend），采用意向治疗口径。
- 成本敏感性分析中的邮件成本为情景参数，不代表真实投放成本。
- Spend 不等同于利润或投资回报率；正式投放还需结合毛利、实施成本、退订影响和长期客户价值。

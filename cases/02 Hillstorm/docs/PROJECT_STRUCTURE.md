# 项目结构说明

本文件记录此次目录重排关系。目录调整以“数据 → 分析 → 演示”为主线，不改变原有 Python 分析逻辑、结构化结果数据或 PPT 内容。说明性 README、设计说明与决策说明统一使用中文表述。

| 原目录或文件 | 当前位置 |
|---|---|
| `1.实验数据审计/` | `1.原始数据与数据审计/1.2 实验数据审计/` |
| `2.AB Test/` | `2.分析/2.1 AB Test/` |
| `3.异质性效应/` | `2.分析/2.2 异质性效应/` |
| `4.Uplift/` | `2.分析/2.3 Uplift/` |
| `5.策略优化/` | `2.分析/2.4 策略优化/` |
| `Hillstorm邮件实验管理层汇报_中文版.pptx` | `3.演示文档/3.1 演示文档/` |
| 原根目录 `README.md` | `docs/README_原始版本.md` |
| `hillstrom_common.py`、`requirements.txt`、`run_all.py` | 保留在项目根目录 |

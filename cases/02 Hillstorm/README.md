1. 从 `1.原始数据与数据审计/1.2 实验数据审计` 查看数据质量、随机分流与基础审计结果。
2. 按 `2.1` 至 `2.4` 依次阅读平均实验效果、稳健性检验、异质性效应、Uplift 验证与策略优化。
